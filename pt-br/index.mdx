## Faça sua primeira requisição à API REST

<Steps>
  <Step title="Obtenha suas credenciais de API" icon="shield-keyhole">
    Siga o guia de [autenticação](/pt-br/credentials) para gerar uma chave de API no console administrativo do Bridge. Se necessário, peça acesso ao administrador do Bridge. Mantenha a chave no servidor.
  </Step>
  <Step title="Verifique a conexão" icon="code">
    Use o cabeçalho `x-api-key` para chamar o [health check](/pt-br/api-reference/health/verificar-integridade) autenticado em `https://api-connect-us.bridge.new/bridge/api/health`.

    Continue na aba **API REST**. Cada endpoint apresenta seus campos, respostas e exemplos.
  </Step>
</Steps>

<Note>
  Custom Connections usa um endpoint separado e uma `captureKey` pública. Siga o [guia de integração](/pt-br/lead-capture/integration). Uma resposta `202` confirma a aceitação, não a entrega no WhatsApp.
</Note>

<a id="build-from-the-published-contract"></a>

## Implemente com base no contrato publicado

- [Crie um Contato e envie uma mensagem](/pt-br/guides/first-conversation) — siga o fluxo completo: Contato → conversa → mensagem.
- [Envie um PDF ou anexo](/pt-br/guides/send-attachments) — checksum, URL de upload, envio do arquivo e mensagem.
- [Envie um template de WhatsApp](/pt-br/guides/send-template) — descubra as variáveis e forneça os valores exigidos do integrador.
- [Inicie uma conversa com um Agente e transfira o atendimento](/pt-br/guides/agent-outbound) — escolha o Agente e entenda `forceSend`, reutilização e recuperação.
- [Crie e mova registros de pipeline](/pt-br/guides/pipeline-records) — crie registros para contatos existentes, repita com `Idempotency-Key`, evite perder mudanças com `expectedRevision`, feche e reabra.
- [Consulte identificadores](/pt-br/guides/identifiers) e [percorra os resultados paginados](/pt-br/guides/pagination) — use os IDs e cursores corretos.
- [Limites de requisições](/pt-br/rate-limits) — compartilhe a cota de requisições e trate respostas `429`.
- [Códigos de erro](/pt-br/error-codes) — interprete os erros da API REST. Custom Connections tem uma [referência de erros](/pt-br/lead-capture/errors) separada.
- [Parâmetros de templates de WhatsApp](/pt-br/templates-and-parameters) — abra conversas com templates de WhatsApp e forneça suas variáveis.
- [Histórico de alterações](/pt-br/changelog) — consulte mudanças que afetam as integrações.

Leia sem MCP pelo [índice trilíngue](/llms.txt), [índice em português](/llms-pt-br.json), [documentação reunida em português](/llms-full-pt-br.json) ou [guia para agentes de IA](/skill.md). Consulte os esquemas exatos no [OpenAPI da API REST de integrações](/pt-br/api-reference/openapi.yaml) ou no [OpenAPI de Custom Connections](/pt-br/api-reference/campaign-leads.openapi.yaml).
