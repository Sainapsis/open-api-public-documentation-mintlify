## Make your first REST API request

<Steps>
  <Step title="Get your API credentials" icon="shield-keyhole">
    Follow [Authentication](/credentials) to generate an API key in the Bridge Admin Console. Ask your Bridge administrator for access if needed. Keep the key on your server.
  </Step>
  <Step title="Check the connection" icon="code">
    Use your `x-api-key` header to call the authenticated [health check](/api-reference/health/health-check) at `https://api-connect-us.bridge.new/bridge/api/health`.

    Continue in the **REST API** tab. Each endpoint lists its fields, responses, and examples.
  </Step>
</Steps>

<Note>
  Custom Connections uses a separate endpoint and public `captureKey`. Follow its [integration guide](/lead-capture/integration). A `202` confirms acceptance, not WhatsApp delivery.
</Note>
