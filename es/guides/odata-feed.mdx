El feed OData entrega los datos de conversaciones de tu espacio de trabajo a herramientas de reportes como Power BI. Esta página cubre los campos del conjunto de entidades `LeadscoutSessions` que indican de dónde vino una sesión. Pide `$metadata` para ver la lista completa de campos y sus tipos.

## Conexión

```text
https://api-connect-us.bridge.new/odata/v1
```

El feed usa autenticación HTTP Basic: el usuario es el id de tu espacio de trabajo y la contraseña es la misma API key que envías en `x-api-key` a la API REST. Una solicitud con solo el encabezado `x-api-key` se rechaza.

## Campos de procedencia

La procedencia describe de dónde vino una sesión. Todos los campos son opcionales y están vacíos cuando Bridge no registró procedencia para la sesión.

| Campo | Tipo | Contenido |
| --- | --- | --- |
| `ProvenanceSource` | `Edm.String` | De dónde vino el contacto, por ejemplo `facebook`, `instagram`, `google`, `whatsapp` o `newsletter`. Equivale a `utm_source`. |
| `ProvenanceMedium` | `Edm.String` | El tipo de canal: `ad` para un anuncio de Meta, `post` para una publicación de Meta, `organic` para un lead o mensaje de WhatsApp orgánico, `bridge` para una campaña de Bridge. En una landing page es el `utm_medium` que envió tu página, en minúsculas. |
| `ProvenanceCampaignId` | `Edm.String` | El id de la campaña: la campaña de la plataforma de anuncios, el `campaignId` enviado en una solicitud outbound o la campaña de Bridge. |
| `ProvenanceContentId` | `Edm.String` | El id del anuncio o contenido dentro de la campaña. |
| `ProvenanceCapturedAt` | `Edm.DateTimeOffset` | Cuándo se capturó la procedencia. |

## Campos que cambian

<Warning>
  `Source` está obsoleto. Sigue presente y conserva el valor que tenía; prefiere los campos de procedencia de arriba.
</Warning>

| Campo | Comportamiento |
| --- | --- |
| `Source` | Obsoleto. Lleva el id de campaña para formularios de Meta, solicitudes de la API outbound y campañas masivas de Bridge; la URL de la landing para anuncios Click-to-WhatsApp y landing pages; y nada para conversaciones orgánicas de WhatsApp. |
| `CampaignCaptureCapturedAt` | Se toma de la fecha de captura de la procedencia, y solo cuando `CampaignCaptureStatus` es `MATCHED`; si no, está vacío. |

## Nombra una campaña desde la API outbound

Una solicitud outbound que envía `campaignId` también puede enviar un `campaignName` opcional. El nombre solo se acepta junto con `campaignId`, se eliminan los espacios al inicio y al final un nombre en blanco se trata como ausente y admite como máximo 200 caracteres. Si la misma campaña llega con nombres distintos, los reportes muestran el más reciente. Consulta la [guía de outbound de Agentes](/es/guides/agent-outbound).
